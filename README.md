# NativeKeyBlocker（NativeKeyBlocker）

> 把游戏自带的 6 个战斗快捷键（1=铲子、2=切卡栏前置、3=植物血量、4=僵尸血量、5=加速、0=手套）各自做成独立开关，默认全屏蔽。屏蔽后这些按键不再触发游戏原生功能（比如按 1 不再举铲子），给其它改键 Mod 腾出按键；

## 安装

把 `dist/NativeKeyBlocker.pmod` 放进游戏的 Mods 目录，或在 Mod 管理里导入。
